# RSCTF archive branch

This branch is a lean RSCTF Repository Bindings distribution generated from the event's archival source. The default branch remains the complete historical archive.

## Imported events

- Slashroot 8 CTF 2024 — Qualifiers
- Slashroot 8 CTF 2024 — Finals

Every challenge is disabled by RSCTF on first import and every event starts hidden. Review flags, attachments, container builds, and descriptions before enabling them. Legacy or non-portable services are retained as archived attachments with source links so the production importer never executes unsupported compose stacks.
